## Negative triggers

1. “Remove duplicate toolbar styling.”
   - Route to `resonance-refactor-isomorphically` unless file splitting is also requested.
2. “Why is Streaming slow?”
   - Route to `resonance-profile-performance` first.
3. “Write an E2E test against the fixture server.”

## Contract checks

A correct run must refuse to call a seam complete when any of these is missing: baseline regression output, characterization for uncovered behavior, Xcode Sources membership, access-control audit, same-device performance evidence for a hot path, or truthful simulator/physical acceptance boundaries.
