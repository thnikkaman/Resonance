# Self-Test

## Positive triggers

1. “Streaming freezes the first time I open it.”
   - Trigger this skill; define cached-catalog size, first-frame golden, and physical/simulator scope before profiling.
2. “Profile remote seek and queue advancement.”
   - Trigger this skill; require a real isolated service and physical-device evidence for audible/runtime claims.
3. “Why did the Xcode build get slower after the split?”
   - Trigger build scenario matrix with symmetric DerivedData conditions.

## Negative triggers

1. “Extract this 2,000-line view into files.”
   - Route to `resonance-decompose-isomorphically` after profiling only if performance is the stated motive.
2. “Deduplicate toolbar styles.”
   - Route to `resonance-refactor-isomorphically`.
3. “Add fixture-server E2E coverage.”
   - Route to `resonance-real-service-e2e`.

## Contract checks

A correct run must reject an optimization recommendation based on one profiler, an unpinned scenario, cross-device A/B data, output drift, or a simulator-only physical/audio claim. It must preserve raw samples and report disputed hypotheses.
